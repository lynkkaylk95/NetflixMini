1. Kết nối với GitHub

Chưa có token? Vào GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Chỉ cấp quyền cho repository của website này, và ở phần "Repository permissions" chọn Contents: Read and write. Token chỉ được lưu trong trình duyệt của bạn (localStorage), không gửi đi đâu khác — nhưng đừng chia sẻ trang admin này hoặc token cho người khác.
